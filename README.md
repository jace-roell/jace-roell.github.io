# Portfolio

Portfolio website documenting my journey as a software engineer. Built with [Next.js](https://nextjs.org/) and deployed to GitHub Pages at [jaceroell.dev](https://jaceroell.dev).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build & deploy

Static export for GitHub Pages:

```bash
npm run build
npm run deploy
```

The `deploy` script publishes the `out` directory via `gh-pages`.
